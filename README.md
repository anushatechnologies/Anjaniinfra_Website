# Anjani Infra - Official Marketing & EPC Website

Anjani Infra Projects (Narsingi) is India's premier Design & Build EPC enterprise unifying Civil RCC Superstructures, Luxury Corporate Fitouts, and High-Performance Glazing Envelopes under one unified roof.

## 🚀 Technology Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: Vanilla CSS / Tailwind CSS with Luxury Theme Palette
- **Icons**: Lucide React
- **Email Integration**: Direct Frontend Client-Side Dispatch (FormSubmit API & Native Mailto)

## 📁 Key Features
- **Landmark Portfolio Directory**: 8+ Turnkey Projects with discipline filtering (Civil, Interior Fitout, Exterior Facade).
- **Dedicated Multi-Page Navigation**: Standalone routes for `/about`, `/services`, `/projects`, `/why-us`, `/contact`.
- **Request Architectural Proposal Modal**: Direct inquiry form with instant email delivery to `venkataraodama660@gmail.com`.
- **Category-Pure Fallbacks**: High-resolution architectural photography with zero broken images.

## 💻 Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:3002](http://localhost:3002) in your browser.

## 📦 Production Build & Export
```bash
npm run build
```
Generates a 100% standalone production bundle ready for Vercel, Netlify, or static hosting.
